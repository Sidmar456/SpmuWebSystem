## Quality & Code Standards

### Error Prevention & Precision
- **Zero-Guessing Policy**: Never invent non-existent APIs, libraries, or unverified syntax.
- **Type Safety & Validation**: Always check types, edge cases, `null`/`undefined` states, and handle exceptions cleanly.
- **Security First**: 
  - Mandatory prepared statements (`PDO` / `mysqli`) to eliminate SQL injection.
  - Strict input sanitization (XSS prevention) and proper CORS handling.
- **Performance & Modern Standards**:
  - **React/Vite**: Use strict state management, proper dependency arrays in hooks, efficient re-render control, modular styling, and clean Vite asset handling.
  - **PHP/MySQL**: Follow PSR-12 coding standards, clean separation of concerns (MVC/Services), optimized query structure, proper indexes, and ACID compliance.

## Code Generation Format
1. **Clean Code**: Fully written, working, copy-paste ready code (no incomplete pseudo-code or missing imports unless requested).
2. **Context First**: Mention required dependencies, file paths, or structural setups briefly before presenting code blocks.
3. **Refactoring Guidelines**: When modifying user code, identify the root cause or defect first before providing the optimized solution.
